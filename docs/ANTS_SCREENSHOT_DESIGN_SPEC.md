# ANT'S トップページ全面刷新：提供スクリーンショット準拠デザイン仕様

## 最優先の参考
ユーザー提供の SENJYU トップページ全体スクリーンショット（会話内添付: Macbook-Air-morikoshi.net.webp）を、**レイアウトとページの流れの最優先参考**とする。実際のスクロール途中で透明度が低い箇所があるため、スクリーンショットで薄く見える要素を完成時の意図的な低コントラストと誤解しない。

参考 URL: https://morikoshi.net/
本レポジトリ: https://github.com/hiroyukimaekawa-lang/ANT-S
作業ブランチ: codex/senjyu-inspired-redesign

## デザイン原則
- 写真を主役とするエディトリアルな設計。セクションごとに大胆な余白。
- オフホワイト、クリーム、生成り、グレージュ、鈍いゴールドなどの落ち着いたパレット。読みやすい本文コントラストを確保する。
- セリフ系ディスプレイ見出し＋読みやすい日本語本文。装飾要素は控えめに。
- 縦に物語が進行するロングページ。SENJYUのHTML/CSS・固有グラフィック・文章・画像の複製はしない。
- ANT'Sのロゴ、会社情報、店舗、サービス、スタッフ、予約導線を正確に保持。
- レイアウト、動き、レスポンシブの組み合わせを重視。静的画像の再現だけで完了としない。

## 動きの仕様
- スクロール表示: IntersectionObserverによる opacity:0→1、translateY(24px)→0、700–1000ms。
- カードは100–180ms程度の時間差で順次表示。見出し→画像→詳細の順を必要に応じて採用。
- 画像は軽いズームや控えめなパララックスのみ。過度な回転、激しい移動、常時パーティクルは避ける。
- IntersectionObserver未対応・JavaScript無効時にも本文を読めるようにする。
- prefers-reduced-motion: reduce でアニメーション停止、初期非表示を解除。
- レンダリング途中をキャプチャした参照画像の低opacityを「完成時の透明度」として採用しない。

## 実装ルール
1. トップページは既存HTML構成の部分的な化粧直しではなく再構築する。
2. 過去の試験的な `redesign.css` と `main.js` 内の動的CSS注入を整理し、既存スタイルの競合を解消する。
3. 画像は assets/ 内のANT'S所有・利用許諾済み画像を優先。画質不足や不足素材は docs/redesign/assets-needed.md に書き出す。SENJYUの画像のホットリンク/流用禁止。
4. PC 1440px / タブレット 768px / モバイル 390px・375px でスクリーンショットを撮り、参考構成と照合する。
5. 下層ページ6件もこのデザインシステムで統一する。ただしトップページ完成→レビュー→全ページ展開の順で進める。
6. 初期フェード中の中途半端な見え方だけで合否判定せず、静止後も確認する。
7. 本番デプロイ・mainマージは禁止。Draft PR #1を更新する。

## Codexへの直近のタスク
まずユーザー提供スクリーンショットに基づくセクション構成を `index.html` に実装し、既存の不完全な仮画像を適切なANT'S素材へ置換。CSS/JSを整理して、アクセシブルなスクロールアニメーションを完成させる。その後、各画面幅でレンダリングを確認する。画像が足りない場合は安全な仮素材（権利確認済み）かレイアウト用プレースホルダを使い、必要素材一覧を残す。PR #1はDraftのままにする。
